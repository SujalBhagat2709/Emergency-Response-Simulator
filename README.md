# Emergency Response Simulator

## Overview

A real-time emergency control center simulator where incidents occur dynamically and resources must be dispatched efficiently.

---

## Features

- Random incident generation
- Resource management
- Live decision making
- Dynamic simulation flow
- Multiple emergency types

---

## Files

- incident.py
- simulator.py

---

## Usage

```bash
python simulator.py
```

---

## Example

```text
⏰ Minute 1

🚨 Incident: Building Fire

Priority: 5

Resources

🚑 Ambulances: 3
🔥 Fire Trucks: 2
🚓 Police Units: 4

Dispatch Team? (y/n): y

🔥 Fire Truck Dispatched
```
